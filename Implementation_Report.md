# Отчет о реализации аутентификации и авторизации

## Введение

В рамках выполнения задания была реализована система аутентификации и авторизации для приложения Valera. Были добавлены регистрация и вход пользователей, JWT-аутентификация, роли пользователей (User/Admin), и ограничения доступа к API.

## Структура изменений

**Файл:** `valera3/Models/User.cs`
**Строки:** 1-22

## Технические детали реализации

### Модель User
```csharp
public class User
{
    public int Id { get; set; }
    [Required]
    [EmailAddress]
    public string Email { get; set; }
    [Required]
    public string PasswordHash { get; set; }
    [Required]
    public string Username { get; set; }
    public string Role { get; set; } = "User";
    public List<Valera> Valeras { get; set; } = new List<Valera>();
}
```

### Проверки авторизации
- Пользователь может создавать, просматривать, обновлять и удалять только свои Валеры
- Администратор может просматривать, обновлять и удалять любые Валеры
- Только администратор может получить список всех Валер
- Проверки реализованы как в сервисе, так и в контроллере

### JWT токен
Содержит следующие утверждения:
- nameid (Id пользователя)
- email (Email пользователя)
- role (Роль пользователя)

### Новые эндпоинты
- POST /api/auth/register - регистрация пользователя
- POST /api/auth/login - вход пользователя
- GET /api/valera/my - получить "своих" Валер
- Все остальные эндпоинты требуют авторизацию
